# 🎯 Number Guessing Game

A simple **Number Guessing Game built using Python**. The player has to guess a randomly generated number within a limited number of attempts.

## ✨ Features

* Random number generation
* Easy and Hard difficulty levels
* Different number of attempts for each difficulty
* Higher/Lower hints after every guess
* Tracks remaining attempts
* Win and lose conditions
* Input validation

## 🛠️ Technologies Used

* **Python**
* `random` module

## 🎮 How to Play

1. Run the program.
2. Choose a difficulty:

   * `easy` → 10 attempts
   * `hard` → 5 attempts
3. Enter your guess.
4. The game tells you whether your guess is **too high** or **too low**.
5. Continue guessing until you find the correct number or run out of attempts.
